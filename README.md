# Atividades-ED2

[cite_start]Este repositório contém as atividades desenvolvidas para a disciplina de Estrutura de Dados 2 (EDCO4B) da UTFPR, campus Apucarana[cite: 5, 191].

## Atividades

* [cite_start]**[Primeira Atividade](./Primeira%20Atividade/)**: Implementação e comparação de performance (tempo e número de comparações) de sete algoritmos de ordenação[cite: 203, 208].
* [cite_start]**[Segunda Atividade](./Segunda%20Atividade/)**: Implementação de *Keysorting* [cite: 4, 21] [cite_start]usando quatro algoritmos de ordenação (Insertion, Merge, Quick e Heap) [cite: 114] para classificar uma base de dados de heróis.
